## About this repository

This repository is confidential, to be used within the scope of Project CAPTURE (<http://capture.isr.tecnico.ulisboa.pt>) for dvelopment and testing of the project outcomes.

The repository includes modles for the following drones:
1. Rotary-wing shuttle drone, based on the platform T-Drones M690B;
2. Fixed-wing target drone, based on the platform Multiplex EasyGlider 4;
3. Marine target drone, based on the platform Traxxas Blast boat.
